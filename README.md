# 星星岛大冒险

给 5-10 岁孩子玩的静态网页学习游戏。不用服务器：双击 `index.html` 就能在浏览器里玩，也可以部署到任何静态托管。进度保存在浏览器的 localStorage 里。

线上地址：https://star-island.pages.dev

## 内容

- **10 个学科区域，435 个关卡，54 种玩法**
  - 区域：语文森林、数学城堡、英语港湾、科学星台、生活小镇、艺术剧院、地理航线、国学文化馆、逻辑实验室、职业体验城。
  - **大游戏**（3D / 物理）：星星卡丁车、星星大冒险（经典横版跳跃：蘑菇、火焰花、无敌星、水管食人花、乌龟壳、弹簧、旗杆城堡，生成关卡后自动模拟验证每枚金币都吃得到）、弹弓物理战、喷射涂涂战（第三人称涂地射击）、星星滚球（3D 空中跑道滚球）。知识题融合在玩法里，比如道具箱、问号砖、答案气球、终点答案圈。
  - **动手玩**（不是选择题）：合十消除、小小收银员、气球猜词、连点成画、汉字积木、水管工、点亮星空、音乐记忆、小厨师点单、对称画、算式建造、安全过马路、拼图、天平、像素涂色、描红、字词寻宝、拨钟、翻翻乐、连连看、分类、排序、拼拼乐。
  - **动作答题**：贪吃蛇、迷宫、跑酷、飞跃之门、神箭手、拆弹、井字棋、打砖块、飞行棋、找一找、节奏大师、叠高塔、抢答擂台、弹弓、接接乐、打地鼠、钓鱼、青蛙跳、赛车、泡泡、气球、星际射击等。
- **操作方式**：大游戏支持触屏和键鼠两种操作，可以自动识别，也可以在关卡介绍里、游戏右上角或家长中心切换。
  - 触屏：画出半透明的摇杆和按钮。
  - 键鼠：方向键 / WASD 移动；FPS 玩法点一下画面锁定鼠标，鼠标瞄准、左键射击。
- **按年级出题**（学前到四年级）：每局随机生成题目。
- **RPG 养成**
  - 每个区域有 3 个 Boss，打赢后夺回知识宝石；集齐 10 颗宝石后挑战最终 Boss 糊涂龙。
  - 角色可以升级、换装；可以孵化、喂养宠物。
  - 商店、扭蛋贴纸图鉴、签到、每日任务、成就、错题本。
- **11 种画风**：童趣卡通、清新立体、精致3D、纸片立体、手绘涂鸦、贴纸拼贴、水彩绘本、黏土软萌、像素复古、水墨国风、霓虹赛博。默认跟随年级，也可以在商店里买新画风，或在家长中心切换。主地图的 3D 浮岛也会跟着画风变化。
- **语音**：约 1.4 万条 edge-tts 语音（晓晓 / Ava 自然音色）已预先生成，其中包括最常出现的 3000 句「数字 + 文字」整句（如算式、价钱、钟点）。其余带数字、名字的随机句子拆成「预录小句 + 预录数字」，用 Web Audio 去掉片段首尾静音后首尾相接播放，听起来是连贯的一句。不用浏览器的机器朗读。
- **点读**：每个选项上都有 🔊，点一下只朗读不作答；题目旁「读选项」按顺序读一遍。学前和一年级默认开启悬停 / 长按选项朗读，并在读完题目后自动读选项（家长中心可关）。按钮、金币等界面文字不朗读。
- **键鼠快捷键**：数字键 1-9 选第几个选项，Enter 确定，Esc 返回或关闭，按钮各自的字母键（如主地图 H 家园、S 商店）。按钮上不显示键帽，鼠标悬停时提示里会写出对应按键；大游戏左下角常驻按键说明。
- **加载**：切换场景前先停在当前画面把下一个场景要用的图片、音效、音乐、语音全部下载好（音频整份存进内存），再搭建新场景，等 3D 模型、贴图、立绘也加载完才显示，关卡的计时和倒计时也从这之后才开始。场景显示出来以后断网，场景里的操作和声音都还能用。真的下载失败（比如断网）会提示重试。弹窗也一样：里面的图片、3D 立绘都就绪才弹出来。加载进度统一显示在屏幕正中间。
- **3D 角色**：15 个主角都是动漫风 VRoid 人物（VRM，MToon 赛璐璐着色，会眨眼、头发和裙摆有物理），动作来自动捕动作包重定向，另有程序生成的坐下、躺下、伏案打字、捧书阅读。24 只宠物是带骨骼动画的 3D 模型，统一用和人物同一套 MToon 动漫着色（平滑法线、偏冷的阴影色、同色系细描边，卡通怪兽换成动漫大眼、写实动物加眼睛高光）。帽子和魔法杖挂在头部和手部骨骼上。Boss 战、涂地射击、家园、探索都用实时 3D，其他界面用离屏渲染的立绘。
- **我的家园（JRPG 风格）**：精致动漫风阁楼小屋（圆角家具 + MToon 着色 + 手绘木地板 / 护墙板贴图、月光光柱、浮尘、彩灯和灯光光晕），窗外有月亮夜景，右上角显示日期和月相。主角和宠物用网格 A* 寻路绕开家具、互相避让；坐沙发、坐椅子打电脑、躺床盖被子、宠物跳上沙发 / 进窝都按骨骼位置对齐家具，不穿模。宠物会自己闲逛、打盹、看月亮、追蝴蝶、追尾巴、打喷嚏、偷偷叼来金币或礼物；半夜 0 点会进入「影时间」。可以点地板（或用 WASD）让主角走过去，也可以摸摸、喂食、玩球、训练、拍照。
  - 宠物分 N / R / SR / SSR / UR 五个稀有度，孵化概率是 50 / 30 / 14 / 5 / 1%，30 次内保底 SSR 以上；孵到重复的宠物会升星。
  - 宠物会按稀有度以不同概率带回「外设装备」：心之护符、守护之盾、治愈之泉、洞察之眼、金币磁铁、智慧之书、勇气之剑、幸运四叶草。装备共 3 个槽，在所有游戏和 Boss 战里生效。概率在装备面板里公示。
  - 出门探索：手绘风的星星小镇、霓虹都市、萤火森林、月光海滩、影时间之塔，按等级解锁。可以带宠物逛，互动有寻宝、购物、许愿、休息、NPC 出题、拍照。
- **家长中心**：可以设置年级、画风、操作方式、音乐 / 朗读 / 音效音量、3D 画质、每日游戏时长，还能导出 / 导入存档。
  - 每日时长到了会锁屏（游戏中也会锁），只有家长答对验证题（两位数乘法）才能「再玩 15 / 30 分钟」「今日时长清零」或「今天不限时」；还剩 5 分钟时会提醒。
- **手机 / 平板**：可以「添加到主屏幕」作为独立 App 全屏打开（PWA，离线也能玩已下载过的内容）；适配 iPhone 刘海 / 灵动岛 / 底部横条和横竖屏切换；屏蔽下拉刷新、左右滑动返回、双指缩放、长按菜单，系统返回键当作游戏里的「返回」。
- **性能**：3D 画质按设备自动分档（省电 / 均衡 / 高清：分辨率、抗锯齿、阴影、帧率上限），运行中帧率跟不上会自动降分辨率 / 降到 30 帧，减少卡顿和发热；也可以在家长中心手动选。

## npm scripts

| 命令 | 作用 |
|---|---|
| `npm run deploy` | 构建 `dist/` 并发布到 Cloudflare Pages（项目 `star-island`） |
| `npm run deploy:init` | 首次部署前创建 Pages 项目 |
| `npm run build` | 只构建 `dist/` |
| `npm run preview` | 本地预览 `dist/` |
| `npm test` | 在无头浏览器里自动通关每种玩法（学前 / 二年级 / 四年级） |
| `npm run test:grade -- <年级> [玩法,...]` | 只测指定年级和玩法 |
| `npm run voice` | 修改题库后补生成语音 |
| `npm run emoji` | 补齐新用到的 emoji 图片 |
| `npm run fonts` | 按新用到的字重新子集化字体 |
| `npm run sfx` | 重新合成答对 / 奖励类音效（需先 `npm i`） |
| `npm run hero-cards -- [角色id,...]` | 增改主角后重新渲染选角色用的大头照和挥手动图（`assets/img/hero/`，需 playwright-core + 本机 Chrome） |

`node tools/pack_models.cjs <源目录> 名字=路径 ...` 用来把 Kenney GLB 打包进 `assets/models/models.js`（贴图内嵌，用 base64 加载，`file://` 下也能用）。

`node tools/pack_chars.cjs <素材目录>` 用来打包带骨骼动画的角色和宠物模型，输出到 `assets/models/c/<key>.js`（按需加载）和 `index.js`。打包时会去掉用不到的动作，并用 gltf-transform 清理数据。

## 代码结构

| 文件 | 内容 |
|---|---|
| `js/data.js` | 基础题库 |
| `js/content*.js` | 出题器 |
| `js/catalog.js` | 区域和关卡目录 |
| `js/engines*.js` | 玩法引擎 |
| `js/arcade.js` | 大游戏公共层：操作、答题浮层；以及平台跳跃、格斗、物理弹弓 |
| `js/arcade3d.js` | 卡丁车、涂地射击 |
| `js/world3d.js` | 3D 主地图 |
| `js/app.js` | 游戏系统 |
| `js/avatar3d.js` | 3D 角色：加载、按画风换材质、描边、立绘截图、实时小舞台 |
| `js/home.js` | 我的家园：3D 小屋、宠物行为、稀有度、装备、孵化 |
| `js/explore.js` / `js/sketch.js` | 出门探索；手绘场景绘制 |
| `js/voiceseg.js` | 语音拆句和数字读法 |
| `js/preload.js` | 切场景 / 开局前预加载素材，加载完才切换、才开始计时 |
| `js/scene-assets.js` | 自动生成：各模块代码里写死的语音 / 表情 / 图片清单（`node tools/scene_assets.cjs`，构建时自动运行） |
| `js/netload.js` | 统计页面上正在加载的全部资源，供切场景 / 弹窗判断是否加载完 |
| `js/device.js` | 手势屏蔽、返回键、横竖屏、PWA 注册、3D 画质分档与自动降级（`Perf.renderer`） |
| `sw.js` / `manifest.webmanifest` | PWA 离线缓存与安装信息（构建时按内容生成缓存版本号） |
